# Synthetic fixtures

All fixture names and content are invented. They never reference real Kahntra product folders.

- `ValidProduct`: populated Inbox and complete status
- `EmptyInbox`: existing Inbox with no visible entries
- `MissingInbox`: status only
- `MissingStatus`: Inbox only
- `MalformedStatus`: invalid supported metadata
- `HiddenAndDirectory`: hidden item excluded; visible directory counted once
- `UnreadableSource`: exercised through an injected filesystem failure
